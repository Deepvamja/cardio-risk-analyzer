❤️ Cardio Risk Analyzer
Machine Learning–Based Cardiovascular Risk Prediction System

Cardio Risk Analyzer is an end-to-end machine learning system that predicts the likelihood of cardiovascular disease based on patient health parameters, built with a strong focus on data preprocessing, model logic, and real-world interpretability.

🚨 The Problem 

Cardiovascular disease is one of the leading causes of death worldwide.
Early risk detection is critical, but:

Medical data is often underutilized

Risk assessment is manual and inconsistent

Preventive screening is not easily accessible

❌ Delayed diagnosis
❌ Missed early warning signs
❌ Limited decision support

💡 The Solution

Cardio Risk Analyzer provides a data-driven risk prediction system that:

Uses patient health metrics

Applies machine learning to estimate risk

Presents results through a simple web interface

Helps in early awareness and preventive decision-making

🧠 What the System Does

Accepts patient health inputs (age, BP, cholesterol, glucose, lifestyle)

Preprocesses and normalizes data

Applies a Logistic Regression model implemented from scratch

Predicts presence or absence of cardiovascular disease

Displays prediction results via a web interface

🧪 Dataset Overview

Source: Public cardiovascular health dataset

Records: ~70,000 patients

Features include:

Age, gender, height, weight

Systolic & diastolic blood pressure

Cholesterol & glucose levels

Lifestyle indicators (smoking, alcohol, activity)

✨ Key Features

🧠 Predictive Risk Assessment

Uses machine learning to estimate cardiovascular risk, enabling early identification of high-risk individuals.

📊 Data Cleaning & Preprocessing

Handles missing values, outliers, categorical encoding, and feature scaling to ensure reliable model behavior.

📈 Exploratory Data Analysis (EDA)

Analyzes feature distributions and correlations to understand medical risk patterns.

⚙️ Algorithm from Scratch

Implements Logistic Regression manually using gradient descent, demonstrating core ML fundamentals beyond libraries.

🧪 Model Evaluation

Evaluates model performance using accuracy and train/test split to check underfitting and overfitting.

🌐 Web-Based Prediction Interface

Provides a Flask-based interface for real-time predictions, bridging ML models and real users.

🧩 System Flow

Patient Data Input
        ↓
Data Cleaning & Scaling
        ↓
Logistic Regression Model
        ↓
Probability Estimation
        ↓
Risk Prediction Output

🛠️ Tech Stack

Machine Learning: Logistic Regression (from scratch)
Programming: Python
Data Processing: NumPy, Pandas
Web Application: Flask
Visualization: Matplotlib
